# Etch-a-Sketch

A browser-based drawing toy inspired by the classic Etch-a-Sketch. Built with HTML, CSS, and vanilla JavaScript as part of The Odin Project foundations curriculum.

## Features

- Interactive grid that colors squares on mouse hover
- Adjustable grid size via user input (up to 100×¹⁰⁰)

## Live Demo

Live Solution: https://topetch-a-sketch.netlify.app

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/tsilvalisbon/etch-a-sketch.git
   cd etch-a-sketch
   ```
2. Open `index.html` in your browser.
3. Draw by hovering over the grid.

## Project Requirements

This project implements the core requirements from The Odin Project:

- 16×¹⁶ grid of square divs created with JavaScript
- Grid laid out using Flexbox
- Hover effect that colors squares like a pen trail
- Button to prompt user for new grid size and regenerate the grid
- Prevent layout overflow and maintain consistent total grid size

## Technologies

- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (DOM manipulation)
